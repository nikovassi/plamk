### Какво беше оптимизирано
- Prerender на всеки route (`react-dom/static`) → съдържанието е в HTML, без чакане на JS.
- Route-level code splitting + `modulepreload` за текущия route; Zod и формата се зареждат само на `/zapitvane`,
  supabase-js — само в `/admin`. Основен JS: ~80 KB gzip (от тях ~62 KB React DOM).
- CSS (~12 KB gzip) е вграден в HTML (без render-blocking заявка); кирилицата и латиницата на шрифта са с `preload`.
- Hero анимациите са само с transform → текстът се рисува в първия кадър (LCP).
- Placeholder визуализациите са статични SVG файлове с lazy loading (не inline DOM).
- Реалните снимки: AVIF + WebP, 4 ширини, `srcset/sizes`, lazy, `fetchpriority=high` само за hero.
- Hero видео: само на desktop без Save-Data / 2G / 3G; на телефон — poster.
- Prefetch на следващите вероятни страници след 2 s idle, изключен при Save-Data / 2G / 3G.

## Ръчна визуална проверка
375×667, 390×844, 768×1024, 1440×900 — светла и тъмна тема: начало, проекти, case study, материал, услуга, формата.
Открити и поправени: хоризонтален overflow от анимацията на стъпките (layout viewport се разширяваше на мобилен),
бутон в header-а, видим на мобилен, празен hero на case study, sticky CTA, което не се показваше на по-къси страници,
генерични съобщения за грешка „Invalid input“ при празни полета, heading order и label/name mismatch.
